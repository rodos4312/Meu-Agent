# Αφαίρεση περιττών μερών από το Meu

Η συντήρηση του Meu χρειάζεται αφαίρεση των εγκαταλελειμμένων υλοποιήσεων,
των εξαρτήσεων και των αποκλειστικών δοκιμών τους. Η απόκρυψη ενός κουμπιού ή
μια συνάρτηση που επιστρέφει πάντα «απενεργοποιημένο» δεν ολοκληρώνει τον καθαρισμό.

## Πρώτο πέρασμα — πραγματικές αφαιρέσεις

- Ολόκληρη η υλοποίηση Settings → Billing της Nous: συνδρομές, αγορά credits,
  αυτόματη ανανέωση, διαχείριση πληρωμών, επιβεβαίωση λογαριασμού και polling.
- Τα χειριστήρια αγοράς/ενεργοποίησης credits μέσα στα σφάλματα του chat.
- Η προτεινόμενη κάρτα Nous, η εφεδρική εμφάνισή της στην εισαγωγή API key και
  η ειδική απόκρυψη των υπόλοιπων παρόχων πίσω από αυτήν.
- Η ειδική υλοποίηση σύνδεσης Nous στο web backend, ο poller της και η διαδρομή
  μεταφοράς εφαρμογών από δωρεάν λογαριασμό.
- Οι ενσωματωμένοι πάροχοι Nous και Solstice, μαζί με τις καταχωρίσεις τους.
- Οι σύνδεσμοι διαχείρισης οργανισμού που άνοιγαν το Nous Portal από τα connectors.
- Οι κλήσεις συλλογής μετρήσεων στη ροή OAuth του web backend.

Παλιός σύνδεσμος `tab=billing` οδηγεί πλέον στα API keys του επιλεγμένου προφίλ.
Αυτή είναι ενεργή μεταφορά παλιού συνδέσμου, όχι διατήρηση του συστήματος πληρωμών.
Οι σύνδεσμοι χρέωσης άλλων παρόχων και η τοπική καταγραφή κόστους παραμένουν χρήσιμοι.

## Υπόλοιπα για επόμενο ελεγχόμενο πέρασμα

Δεν δηλώνονται αφαιρεμένα από ολόκληρο το αποθετήριο:

| Υπόλοιπο | Γιατί χρειάζεται ξεχωριστή αφαίρεση |
| --- | --- |
| `hermes_cli/nous_billing.py`, προβολές λογαριασμού και παλιά billing RPC | Χρησιμοποιούνται ακόμη από εντολές CLI/TUI. Πρέπει να αφαιρεθούν μαζί οι εντολές, τα συμβόλαια και οι αποκλειστικές δοκιμές τους. |
| Desktop `free-tier`, μεταφορά λογαριασμού και φιλοξενούμενα Nous connectors | Έχουν κοινά σημεία με τοπικά MCP, κάρτες εφαρμογών και onboarding. Απαιτείται διατήρηση και δοκιμή των τοπικών connectors. |
| Παλιές υποδομές `shared-metrics` και desktop metrics | Η αποστολή έχει ήδη απενεργοποιηθεί από την πολιτική Meu. Παραμένουν κλήσεις, τύποι και προσαρμογείς που χρειάζονται φυσική αφαίρεση. |
| Nous-only προτάσεις μοντέλων, Tool Gateway και βοηθητικές ροές CLI | Η αφαίρεση του παρόχου δεν διαγράφει αυτόματα όλα τα βοηθητικά τμήματά του. Χρειάζεται έλεγχος εισαγωγών και κλήσεων. |
| Παλιό υλικό παρουσίασης και upstream τεκμηρίωση | Προσαρμογή των οδηγιών του Meu· διατήρηση άδειας, απόδοσης προέλευσης και χρήσιμης τεχνικής τεκμηρίωσης. |

Δεν θεωρούνται περιττά η μνήμη, τα skills, τα plugins, τα τοπικά MCP, οι βοηθοί,
τα προγραμματισμένα έργα, τα εργαλεία και η ανάκτηση εγκατάστασης. Οι προεπιλογές
εγκρίσεων δεν αλλάζουν σε αυτόν τον καθαρισμό.

## Απόδειξη του πρώτου περάσματος

Τα tests χρησιμοποιούν προσωρινό προφίλ, τον πραγματικό κατάλογο και τις πραγματικές
διαδρομές backend. Απαγορεύουν τις εξωτερικές συνδέσεις. Η παλιά υλοποίηση αποτυγχάνει
σε δύο ελέγχους αφαίρεσης· η νέα περνά. Πρόσθετοι έλεγχοι καλύπτουν API keys,
διαχωρισμό προφίλ, παλιούς συνδέσμους και σφάλματα άλλων παρόχων.

Ο αριθμός αφαιρεμένων γραμμών δεν αποτελεί μέτρηση βελτίωσης RAM ή ταχύτητας.
Νέα διανομή δεν χαρακτηρίζεται έτοιμη πριν ολοκληρωθούν οι αντίστοιχοι έλεγχοι Windows.
