# Meu 0.1.0-rc.2 — ιδιωτικό πλήρες δοκιμαστικό Windows

Περιλαμβάνει το περιβάλλον Windows, τον ενσωματωμένο πυρήνα και την Coding Engine από το ίδιο commit.
Η εργασία ξεκινά από το chat, με αυτόματη προετοιμασία έργου και καθαρή παρουσίαση αποτελέσματος.
Περιλαμβάνει τις διορθώσεις ιδιωτικού CI, ανάκτησης και επανακατασκευής Windows με read-only bytecode.

Ο εγκαταστάτης διατηρεί την υπάρχουσα ταυτότητα Meu και τους φακέλους δεδομένων. Δεν απαιτεί απεγκατάσταση.
Η ιδιωτική κατασκευή ελέγχει εγκατάσταση, εκκίνηση πραγματικού πυρήνα, σύνδεση του παραθύρου και επανεγκατάσταση
σε προσωρινό Windows runner. Η δοκιμή του πραγματικού προφίλ του ιδιοκτήτη παραμένει ξεχωριστή.

Αυτή η ροή δημιουργεί μόνο ιδιωτικά CI artifacts. Δεν δημοσιεύει GitHub Release ή δημόσια ενημέρωση.
Το Android Core Test παραμένει ξεχωριστό APK και θα αναβαθμιστεί με το ίδιο ελεγμένο runtime revision.
