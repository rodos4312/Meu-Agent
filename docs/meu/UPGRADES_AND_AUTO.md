# Συντονισμένη αναβάθμιση και Auto συνομιλίας

Η αναβάθμιση σε 0.1.0-dev.5 ελέγχει την πραγματική Git έκδοση του ήδη
εγκατεστημένου backend. Ένας backend που απλώς ξεκινά δεν θεωρείται πλέον
ενημερωμένος. Η συσκευασμένη εφαρμογή Meu συγκρίνει την έκδοσή του με το
αμετάβλητο commit του installer και ζητά την υπάρχουσα διαδικασία εγκατάστασης
με ακριβές pin όταν ο backend είναι παλιότερος.

Η ενημέρωση αφορά μόνο το `rodos4312/Meu-Agent`, στον κλάδο
`dev/meu-foundation`. Δεν αλλάζει το `main`, δεν κάνει reset ή stash τοπικών
αλλαγών και δεν υποβαθμίζει νεότερο backend. Αποκλίνουσα ιστορία, διαφορετικός
κλάδος, μη αναγνώσιμη έκδοση ή αποτυχία λήψης σταματούν την ενημέρωση με σφάλμα.
Ο installer σταματά τον gateway μέσω του υπάρχοντος ελέγχου ενεργών εργασιών
πριν αλλάξει κώδικα και επαναδημιουργεί το περιβάλλον εκτέλεσης με τα κλειδωμένα
dependencies. Τα δεδομένα προφίλ παραμένουν έξω από τον φάκελο πηγαίου κώδικα.
Αυτό δεν ενεργοποιεί γενικό αυτόματο updater ή νέο κανάλι διανομής.

Το μενού μοντέλου της συνομιλίας προσφέρει `Auto · Flash / Pro` στα Sessions
και στο κανονικό Bot Chat. Η επιλογή είναι αποθηκευμένη στην πολιτική της
συγκεκριμένης συνομιλίας, επανέρχεται μετά από επαναφόρτωση και ακολουθεί τους
υπάρχοντες ελέγχους αναθεώρησης/ιδιοκτησίας και αναβολής μέχρι το επόμενο turn.
Χειροκίνητη επιλογή Flash ή Pro κλείνει το Auto μόνο εκεί. Δεν αλλάζει τα
defaults άλλων συνομιλιών ή προφίλ. Τα νέα drafts δείχνουν Auto όταν το
προεπιλεγμένο DeepSeek έχει ενεργή αυτόματη επιλογή στις ρυθμίσεις.

Το `deepseek-auto` είναι αποκλειστικά αναγνωριστικό επιλογής της επιφάνειας:
στο όριο δημιουργίας/αλλαγής πολιτικής μετατρέπεται σε πραγματικό μοντέλο και
ξεχωριστή ρύθμιση routing. Δεν αποστέλλεται ως model ID στο API. Η επιλογή
Flash/Pro παραμένει τοπική, χωρίς πρόσθετη χρεώσιμη κλήση ταξινόμησης. Η
ιδιωτικότητα και οι υπάρχουσες εγκρίσεις μνήμης, skills και computer use δεν
αλλάζουν. Το Bot Chat συνεχίζει να αναγνωρίζεται από `(profile, "Bot Chat")`.

## Έλεγχοι αποδοχής

- Πραγματικό προσωρινό Git checkout: ίση, παλιότερη και νεότερη έκδοση,
  τοπικές αλλαγές και λάθος κλάδος.
- Πραγματικό Windows installer repository stage με τοπικό Git remote:
  ακριβές artifact pin, νεότερο remote tip, άρνηση υποβάθμισης και διατήρηση
  δοκιμαστικών δεδομένων/τοπικών αλλαγών.
- Πραγματική αποθήκευση πολιτικής gateway και δύο ανεξάρτητες συνομιλίες:
  Auto → χειροκίνητο, επαναφορά πολιτικής και αμετάβλητο profile model config.
- Windows Electron με απομονωμένο `MEU_HOME`, πραγματικό Python backend και
  προσομοιωμένο endpoint: εμφάνιση/επιλογή Auto, πραγματικά model IDs,
  επαναφόρτωση και Bot Chat.

Οι έλεγχοι πρέπει να περάσουν στο ακριβές δημοσιευμένο commit πριν θεωρηθεί
ο νέος installer διαθέσιμος. Παραμένουν εκκρεμή η υπογραφή διανομής, το πλήρες
κανάλι αυτόματων ενημερώσεων, η αξιολόγηση συντονιστή σε πραγματικό έργο,
η παρατεταμένη δοκιμή σταθερότητας/μνήμης και ο συνολικός έλεγχος της ορατής
μετονομασίας σε Meu.
