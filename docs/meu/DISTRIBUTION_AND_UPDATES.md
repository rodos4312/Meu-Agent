# Διανομή και ενημερώσεις Meu

Η ανάπτυξη παραμένει στο `rodos4312/Meu-Agent`, αποκλειστικά στον κλάδο
`dev/meu-foundation`. Ο updater Windows ελέγχει μόνο τις δικές μας δημοσιευμένες
εκδόσεις GitHub Releases. Δεν ακολουθεί το `main` ή ενημερώσεις της Nous.

## Δωρεάν διαδρομή και επιλογή χρήστη

Δεν απαιτείται αγορά πιστοποιητικού ή συνδρομή υπογραφής. Από την έκδοση
`0.1.0-dev.8` ο updater χρησιμοποιεί Ed25519: το δημόσιο κλειδί
`apps/desktop/meu-update-key.json` ενσωματώνεται στον κώδικα της εφαρμογής,
ενώ το ιδιωτικό κλειδί υπογράφει το manifest κάθε έκδοσης. Κλειδί από το
δίκτυο, μεταβλητή runtime ή επεξεργασμένο sidecar δεν αλλάζει την εμπιστοσύνη.

Ο υπάρχων έλεγχος εκτελείται στην εκκίνηση, καθημερινά όσο μένει ανοικτή η
εφαρμογή και στην επιστροφή σε αυτήν εφόσον έχει περάσει το διάστημα ελέγχου.
Νέα έκδοση εμφανίζει διακριτική ειδοποίηση που ανοίγει την οθόνη ενημερώσεων.
Η λήψη και εγκατάσταση ξεκινούν μόνο από την επιλογή ενημέρωσης του χρήστη.
Κλείσιμο της ειδοποίησης αναβάλλει τις υπενθυμίσεις για 24 ώρες.
Δεν γίνεται αυτόματη λήψη, εγκατάσταση στο κλείσιμο ή διακοπή ενεργής εργασίας.
Από τη `0.1.0-dev.11`, η ρητή επιλογή «Ενημέρωση» εκτελεί τον επαληθευμένο
installer αθόρυβα και ξανανοίγει την εφαρμογή, χωρίς δεύτερο οδηγό εγκατάστασης.
Χωρίς σύνδεση εμφανίζεται αποτυχία ελέγχου, όχι ψευδής δήλωση ότι είμαστε ενημερωμένοι.

Η δική μας κρυπτογραφική υπογραφή ελέγχει την προέλευση των ενημερώσεων· δεν
είναι πιστοποιητικό αναγνωρισμένου εκδότη Windows. Οι προειδοποιήσεις
Windows/Chrome μπορεί να παραμένουν. Δεν αλλάζουμε την προστασία του συστήματος.

## Έλεγχοι πριν από εγκατάσταση

- Επιλέγονται μόνο δημοσιευμένες νεότερες εκδόσεις `meu-vVERSION`, στο κανάλι
  `meu-preview`. Drafts, ξένα tags και υποβαθμίσεις αγνοούνται.
- Η υπογραφή δεσμεύει repository, κλάδο, κανάλι, έκδοση, commit, όνομα αρχείου,
  μέγεθος, SHA-256 και SHA-512. Η δωρεάν διαδρομή δεν υποβαθμίζεται σε έλεγχο
  ενός απλού hash ή σε εμπιστοσύνη προς οποιονδήποτε Windows εκδότη.
- Τα metadata και τα αρχεία προέρχονται από το δικό μας GitHub Releases.
  Ο εγγενής updater πρέπει να επιστρέφει ακριβώς το υπογεγραμμένο αρχείο,
  μέγεθος και SHA-512. Απαγορεύονται web installers και διαφορικές λήψεις.
- Ελέγχονται ξανά τα πραγματικά bytes μετά τη λήψη, ακόμη και από cache.
  Αλλοίωση ή λάθος υπογραφή εμποδίζει την εγκατάσταση πριν σταματήσει ο backend.
- Διατηρείται επαληθευμένος installer και καταγραφή ανάκτησης. Το SQLite backup
  ακολουθεί την ήδη αποθηκευμένη προτίμηση. Ο canonical gateway μπορεί να
  αρνηθεί διακοπή όταν εργάζεται. Δεν προστίθεται `force`.
- Μετά την αναβάθμιση ο pinned bootstrap χρησιμοποιεί τον backend του ακριβούς
  commit της νέας εφαρμογής. Αποτυχία παράδοσης στον installer επαναφέρει τη σύνδεση.

Οι έλεγχοι στέλνουν μόνο αιτήματα για δημόσια metadata στο GitHub. Δεν στέλνουν
API keys, συνομιλίες, μνήμη, στατιστικά χρήσης ή αναγνωριστικό εγκατάστασης.
Οι προτιμήσεις έγκρισης μνήμης, skills και εργαλείων δεν αλλάζουν.

## Κλειδί και προετοιμασία έκδοσης

Το `scripts/create-meu-update-key.ps1` δημιουργεί το κλειδί μία φορά. Αρνείται
αντικατάσταση υπάρχοντος κλειδιού. Το ιδιωτικό αποθηκεύεται στο αγνοημένο
`.meu-tooling/meu-update-key/private-key.dpapi`, με Windows DPAPI για τον τρέχοντα
λογαριασμό και περιορισμένα δικαιώματα φακέλου. Δεν ενσωματώνεται στην εφαρμογή.
Απαιτείται ασφαλής εφεδρεία του κλειδιού πριν από δημόσια διανομή: απώλειά του
σημαίνει ότι οι υπάρχουσες εγκαταστάσεις δεν μπορούν να εμπιστευτούν νέο κλειδί
μέσω αυτού του καναλιού και θα χρειαστούν χειροκίνητη εγκατάσταση.

Με εξουσιοδοτημένη σύνδεση στο επίσημο GitHub CLI, το
`scripts/configure-meu-update-key.ps1 -GitHubCliPath <absolute-gh-path>` αποθηκεύει
το ιδιωτικό κλειδί στο Actions secret `MEU_RELEASE_PRIVATE_KEY` του συγκεκριμένου
repository. Δεν διαβάζει κρυφά Git credentials. Το secret διατίθεται μόνο στο
τελικό βήμα υπογραφής manifest, όχι στο build ή στις δοκιμές. Δεν εμφανίζεται
σε εντολές, logs, artifacts ή install stamp.

Πριν από διανομή ο Defender ελέγχει installer και αποσυμπιεσμένο φάκελο.
Έλλειψη scanner, σφάλμα ή ανίχνευση σταματούν το upload. Η προετοιμασία έκδοσης
ελέγχει επίσης ότι το πραγματικό ProductVersion και τα hashes της σάρωσης
ταυτίζονται με το πακέτο. Μόνο τότε υπογράφεται το manifest με το αντίστοιχο κλειδί.

Το Windows workflow δέχεται `prepare_release`, tag `meu-release-request-VERSION`
ή commit με τίτλο ακριβώς `release(meu): prepare VERSION` στον κλάδο
`dev/meu-foundation`. Ο τελευταίος τρόπος επιτρέπει προετοιμασία μέσω της
συνδεδεμένης εφαρμογής GitHub χωρίς αλλαγή του default branch `main` ή επιπλέον
τοπικά διαπιστευτήρια. Ελέγχει ancestry και έκδοση, εκτελεί
όλους τους ελέγχους Windows/Linux και δημιουργεί μόνο **draft prerelease**.
Το draft δεν εμφανίζεται στους εγκατεστημένους Meu. Η δημοσίευση είναι χωριστό
βήμα, αφού δοκιμαστεί πραγματική αναβάθμιση και αποτυχία εγκατάστασης.

Η προετοιμασία έκδοσης περιλαμβάνει πλέον ξεχωριστή δοκιμή native αναβάθμισης
σε φρέσκο Windows runner. Χρησιμοποιεί το υπογεγραμμένο candidate
`0.1.0-dev.11` από το run `41505525208` και το νέο candidate. Η dev.11 πέρασε
τους τέσσερις ελέγχους Linux/Windows, σάρωση και κύκλο installer. Η παλιότερη
δοκιμή dev.8 → dev.11 πέρασε τις απορρίψεις υπογραφής και αλλοιωμένων bytes,
αλλά δεν ολοκλήρωσε τη θετική μετάβαση και διακόπηκε για διάγνωση. Δεν
θεωρείται πράσινη δοκιμή αναβάθμισης. Το νέο baseline ελέγχει τη διαδρομή μετά
την πρώτη χειροκίνητη εγκατάσταση με τον αθόρυβο updater. Πριν
εκτελέσει installer ελέγχει και τα δύο manifests με το ενσωματωμένο δημόσιο
κλειδί και επαληθεύει τα πραγματικά bytes. Ελέγχει απόρριψη πλαστού manifest
και αλλοιωμένης λήψης, πραγματική παράδοση στον NSIS, αλλαγή εγκατεστημένης
έκδοσης, αυτόματη εκκίνηση και επανάνοιγμα του νέου renderer. Το δοκιμαστικό
προφίλ περιέχει πραγματικό SessionDB με επινοημένη συνομιλία, config, ψεύτικο
API key, μνήμη και skill, που επαληθεύονται ξανά μετά τη διαδικασία.
Επαληθεύεται επίσης το πραγματικό αποθηκευμένο zoom της εφαρμογής. Το αρχικό
baseline είναι προσωρινό artifact: πριν λήξει χρειάζεται αντικατάσταση από
επαληθευμένη δημοσιευμένη έκδοση, όχι παράκαμψη ελέγχων αν η λήψη αποτύχει.

Σε αυτή τη δοκιμή ελέγχεται το πραγματικό native updater και ο installer,
αλλά τα αρχεία παρέχονται από ελεγχόμενη Electron session και ο agent backend
δεν εκκινείται. Δεν αντικαθίσταται ο updater ή το IPC του. Δεν υπάρχει πλέον
driver που πατά κουμπιά στον παλιό οδηγό NSIS: η εγκατάσταση πρέπει να
ολοκληρώνεται από τον πραγματικό αθόρυβο updater. Κάθε κλήση δοκιμής έχει
χρονικό όριο και καταγράφεται το συγκεκριμένο στάδιο αποτυχίας. Η δοκιμή αυτή
δεν αποδεικνύει λειτουργία δημόσιου καναλιού, μετάβαση backend ή πλήρη
αυτόματη ανάκτηση μετά από αποτυχημένη εκτέλεση installer. Αυτά παραμένουν
ξεχωριστά σημεία ελέγχου πριν χαρακτηριστεί ολοκληρωμένη η διανομή.

## Κατάσταση και όρια

Η native δοκιμή dev.11 → dev.12 ολοκληρώθηκε επιτυχώς στο run `41511726919`:
απόρριψη πλαστού manifest και αλλοιωμένου installer, πραγματική εγκατάσταση,
αυτόματη επανεκκίνηση και διατήρηση του δοκιμαστικού προφίλ. Η dev.12 παραμένει draft.

Το `test-meu-backend-upgrade.ps1` προσθέτει ανεξάρτητη δοκιμή σε καθαρό Windows
runner: πλήρης εγκατάσταση backend στο pin της dev.11, εκκίνηση πραγματικού
canonical gateway, αναβάθμιση στο commit του workflow και έλεγχος ότι τόσο ο
client όσο και ο gateway αναφέρουν το νέο SHA. Ελέγχει επίσης διατήρηση ψεύτικου
API key, μνήμης και skill. Χρησιμοποιεί πραγματικά GitHub downloads και τον
installer, χωρίς mock gateway. Παραλείπονται μόνο οι προαιρετικές λήψεις browser
και computer-use driver στο δοκιμαστικό προφίλ. Δεν αποτελεί δοκιμή δημόσιου
desktop feed ή μετάβασης μέσω του UI. Η επιτυχία της απαιτείται πλέον πριν
δημιουργηθεί επόμενο release draft· η προσθήκη της από μόνη της δεν είναι
απόδειξη επιτυχούς εκτέλεσης.

Η πρώτη πλήρης εκτέλεση (`41517591990`) εγκατέστησε και εκκίνησε επιτυχώς την
παλιά υπηρεσία, αλλά εντόπισε σφάλμα στην αναβάθμιση: σε detached HEAD το Git
δεν επιστρέφει όνομα κλάδου και το PowerShell καλούσε `Trim()` πάνω σε null.
Η ανάγνωση πλέον μετατρέπει την κενή έξοδο σε string. Η δοκιμή αναπαραγωγής
καλύπτει εγκατάσταση και με κλάδο και με detached HEAD, διατηρώντας τους
ελέγχους μη υποβάθμισης, ενεργής εργασίας και τοπικών αλλαγών.

Το δημόσιο κλειδί δημιουργήθηκε και ενσωματώθηκε. Το ιδιωτικό αποθηκεύτηκε στο
Actions secret `MEU_RELEASE_PRIVATE_KEY` του Meu στις 02-11-2026, μετά από ρητή
έγκριση και σύνδεση του ιδιοκτήτη. Η αντιστοιχία του με το δημόσιο κλειδί
επαληθεύτηκε πριν από την αποθήκευση. Μεταφέρθηκε κρυπτογραφημένο μέσω μνήμης,
χωρίς αποκρυπτογραφημένο αρχείο, κωδικό λογαριασμού ή ιδιωτικό κλειδί σε logs.
Δεν έχει δημοσιευτεί έκδοση σε ενεργό κανάλι και δεν έχει ολοκληρωθεί πραγματική
αναβάθμιση μεταξύ δύο δημοσιευμένων εκδόσεων. Οι δοκιμές με προσομοιωμένο native
updater δεν αντικαθιστούν αυτή τη δοκιμή.

Οι παλιές preview εκδόσεις χρειάζονται μία χειροκίνητη εγκατάσταση της πρώτης
έκδοσης με το δημόσιο κλειδί. Από εκεί και μετά μπορούν να χρησιμοποιούν το κανάλι.
Η διατήρηση παλιού installer δεν αποτελεί πλήρη αυτόματη υποβάθμιση backend και
βάσης δεδομένων. Η πρώτη αναβάθμιση μπορεί να μην έχει προηγούμενο cached installer.

Στις 02-11-2026 το αρχικό artifact `0.1.0-dev.6` ταυτίστηκε με το αρχείο GitHub
και οι σαρώσεις ZIP/EXE με Defender δεν εντόπισαν απειλή. Ο ακριβής λόγος της
προειδοποίησης Chrome παραμένει ανεπιβεβαίωτος· δεν χαρακτηρίζεται ψευδής συναγερμός.
