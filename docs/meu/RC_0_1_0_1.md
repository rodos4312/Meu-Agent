# MEU vNext 0.1.0-rc.1

Ιδιωτική δοκιμαστική έκδοση Windows x64. Περιλαμβάνει ολόκληρο το περιβάλλον Windows και τον ενσωματωμένο πυρήνα, με βάση το commit `4d505029568faf214d64f7fc1d1f6ede1074c6b0`.

- Νέα Coding Engine μέσω Chat, με σχεδιασμό, ελεγχόμενες εγκρίσεις, απομονωμένες αλλαγές, ελέγχους και «Διατήρηση / Απόρριψη».
- Περιλαμβάνει τις προηγούμενες βελτιώσεις εκκίνησης, Chat και δρομολόγησης μοντέλων.
- Αφαίρεση των ενεργών υπηρεσιών Nous Portal, Nous API, τηλεμετρίας και συμβατότητας με παλιές ρυθμίσεις Nous.
- Διατηρούνται DeepSeek, MCP, Skills, Plugins, μνήμη, Coding Engine, pairing, συγχρονισμός και File Transfer.
- Διατηρούνται η άδεια MIT και οι νόμιμες αναφορές προέλευσης.

Ο εγκαταστάτης περιλαμβάνει τον πυρήνα και τις κλειδωμένες εξαρτήσεις του. Η πρώτη εκκίνηση δεν χρειάζεται πρόσβαση στο ιδιωτικό GitHub για λήψη πηγαίου κώδικα. Η χρήση διαδικτυακών μοντέλων και υπηρεσιών εξακολουθεί να απαιτεί σύνδεση και τα δικά σας κλειδιά.

Η RC εγκαθίσταται χειροκίνητα. Δεν υπάρχει αυτόματη ενημέρωση από το ιδιωτικό repository. Η εφαρμογή χρησιμοποιεί την υπάρχουσα ταυτότητα και τον υπάρχοντα φάκελο δεδομένων MEU, οπότε η εκτέλεση του εγκαταστάτη αναβαθμίζει την εφαρμογή Windows. Κρατήστε διαθέσιμο τον προηγούμενο εγκαταστάτη για επιστροφή.

Το EXE είναι χωρίς εμπορική υπογραφή Authenticode. Παρέχονται SHA-256, ακριβές commit, αναφορά Defender και αποτέλεσμα δοκιμής εγκατάστασης από προσωρινό GitHub runner. Αυτή η ιδιωτική χειροκίνητη RC δεν είναι υπογεγραμμένο πακέτο του δημόσιου updater.

Γνωστοί περιορισμοί: η Coding Engine απαιτεί ήδη υπάρχον τοπικό έργο Git. Η «Διατήρηση» κρατά το απομονωμένο αποτέλεσμα· δεν το ενσωματώνει αυτόματα στο αρχικό έργο. Η παραγωγή EXE/APK εξαρτάται από το είδος του έργου και τα διαθέσιμα εργαλεία. Οι δοκιμές CI δεν πιστοποιούν πραγματικές κλήσεις σε χρεώσιμα μοντέλα. Η έκδοση Flutter Android δεν περιλαμβάνεται σε αυτόν τον εγκαταστάτη Windows.
